## What I deliver

I implement Odoo as a production ERP, not a collection of disconnected apps. Typical engagements include:

1. **Discovery** — map finance, HR, inventory, and sales processes
2. **Architecture** — module boundaries, data ownership, and upgrade path
3. **Build** — custom addons, reports, portals, and integrations
4. **Localization** — Saudi e-invoicing, Arabic UX, and local compliance
5. **Go-live** — data migration, user training, and hypercare

## Delivery standards

- One Git repository per client production instance where possible
- Clear module names (`hr_*`, `portal_*`, `zatca_*`) instead of dump folders
- Private client repos; public documentation only in this portfolio
- No Odoo Enterprise source in public repositories
- README, `.gitignore`, and a short module index in every delivery repo

See [DELIVERY.md](./DELIVERY.md) for the working checklist I use on projects.
